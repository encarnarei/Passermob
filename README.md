## Introdução

**Este passador** é uma ferramenta desenvolvida para rodar no **Termux**, utilizando **ADB** para trabalhar com dispositivos Android.

## Recursos

- 📱 Detecção de dispositivos Android via ADB
- 🔗 Pareamento de dispositivo
- 🔎 Opçoes de gerenciamento de bypass
- 💻 Compatível com Termux + `android-tools`

## Requisitos

- Android
- Termux
- Python 3
- ADB / `android-tools`
- Permissões necessárias para acessar os arquivos utilizados pelo projeto
- Um dispositivo Android conectado ou pareado via ADB quando necessário
